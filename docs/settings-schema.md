## Schema Types Guide

### When to Use Each Type

**Article:**
- Use for: Blog posts, news articles
- Don't use for: Product pages, static pages

**Product:**
- Use for: E-commerce items, services
- Don't use for: Blog posts, informational content

**Event:**
- Use for: Conferences, workshops, webinars
- Don't use for: Regular blog posts
