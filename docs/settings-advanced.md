## Troubleshooting

### Issue: Performance Problems

**Common Causes:**

---

### Issue: Import Fails

**Symptoms:** Error when importing settings

**Common Causes:**
- Cause 1: Invalid JSON format
- Cause 2: Version mismatch
- Cause 3: Missing required fields

**Solutions:**
1. Validate JSON format
2. Check plugin version compatibility
3. Review import file structure

---

### Issue: Debug Logs Growing

**Symptoms:** Large log files

**Common Causes:**
- Cause 1: Debug mode left on
- Cause 2: High verbosity level
- Cause 3: No log rotation

**Solutions:**
1. Disable debug mode when not needed
2. Lower log verbosity
3. Set up log rotation
