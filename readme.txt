Professional SEO plugin with a modern UI, built for clarity and simplicity: diagnostics, validation, schema, social previews, redirects, robots.txt, and IndexNow.

== Description ==

Clarity-First SEO helps you manage core technical SEO settings with a clean, focused interface.

Features:
* Site Diagnostics (site-wide checks: sitemap, robots signals, indexing blocks, canonical consistency)
* Page Diagnostics (read-only inspection: title, description, canonical, robots, OG/Twitter tags, schema JSON-LD)
* Robots.txt Editor & Validator
* Redirect Manager (manual redirects)
* IndexNow (notify participating search engines on publish/update)
* Bulk SEO editing (titles/descriptions and more)

Notes:
* This plugin is designed to be clear and minimal. It does not guarantee rankings or indexing.
* Avoid running multiple SEO plugins at the same time to prevent duplicate tags.

== Installation ==

1. Upload the `clarity-first-seo` folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to: Clarity-First SEO → Settings
4. Confirm your sitemap and robots defaults, then run Diagnostics

== Frequently Asked Questions ==

= Does this plugin improve rankings? =
No. It helps you configure and verify technical SEO signals. Rankings depend on many factors.

= Can I use this with Rank Math / Yoast? =
Not recommended. Multiple SEO plugins can output duplicate meta tags and cause conflicts.

= Does IndexNow submit to Google? =
No. Google does not use IndexNow. Use Google Search Console for Google indexing workflows.
